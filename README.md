# 🛒 E-commerce Sales Analysis using Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing an E-commerce sales dataset using Microsoft Excel. The objective is to develop practical Data Analyst skills by performing data cleaning, data transformation, statistical analysis, Pivot Table summarization, and interactive dashboard creation.

This project demonstrates how raw sales data can be transformed into meaningful insights to support business decision-making.

## 🎯 Project Objectives

- Import and organize E-commerce sales data in Excel.
- Clean and validate data to improve data quality.
- Identify and remove duplicate records.
- Handle missing values and inconsistent formatting.
- Remove irrelevant columns where necessary.
- Apply Excel formulas and functions for data analysis.
- Combine tables using XLOOKUP or VLOOKUP.
- Perform descriptive statistical analysis.
- Create Pivot Tables and PivotCharts.
- Develop an interactive sales dashboard.
- Present key findings through a concise business summary.

## 🔍 Project Workflow

### 1. Data Import and Organization

- Import the dataset into Microsoft Excel.
- Convert the raw data into a structured Excel Table.
- Rename worksheets and organize the workbook.
- Apply appropriate number, date, and text formats.

### 2. Data Cleaning and Transformation

- Identify and remove duplicate records where appropriate.
- Inspect missing and blank values.
- Correct inconsistent text, date, and number formats.
- Validate data using appropriate checks.
- Identify and remove irrelevant columns when necessary.
- Document cleaning decisions to maintain data quality.

### 3. Excel Formulas and Functions

Apply Excel formulas to calculate and analyze business metrics.

| Function | Purpose |
|---|---|
| `SUM()` | Calculate total sales or other numeric totals |
| `AVERAGE()` | Calculate average values |
| `COUNT()` | Count numeric entries |
| `COUNTA()` | Count non-empty cells |
| `COUNTIF()` | Count records matching a condition |
| `IF()` | Apply logical conditions |
| `TEXT()` | Format or extract information as text |
| `XLOOKUP()` / `VLOOKUP()` | Retrieve and combine information from related tables |
| `MIN()` / `MAX()` | Identify minimum and maximum values |
| `MEDIAN()` / `MODE.SNGL()` | Calculate median and mode |
| `STDEV.S()` | Calculate sample standard deviation |

The functions will be applied according to the actual columns and business questions in the dataset.

### 4. Descriptive Statistical Analysis

Calculate relevant statistical measures, including:

- Mean
- Median
- Mode
- Standard deviation
- Minimum and maximum values
- Count and range

Use Excel formulas or the Analysis ToolPak to examine the distribution and variation of relevant numeric fields.

### 5. Pivot Table Analysis

Create Pivot Tables to summarize sales data across relevant dimensions, such as:

- Product or category
- Customer or region, if available
- Sales period, if available
- Sales totals and averages
- Transaction counts

Use sorting, filtering, and grouping where appropriate to identify useful patterns.

### 6. Data Visualization

Create at least three suitable chart types, such as:

- **Column Chart:** Compare sales across categories or periods.
- **Bar Chart:** Compare product or regional performance.
- **Pie Chart:** Show the proportion of sales across selected categories.

Also create PivotCharts and Sparklines where appropriate.

### 7. Interactive Dashboard

Develop an Excel dashboard that presents important business metrics and visual insights.

Potential dashboard components include:

- Key Performance Indicators (KPIs)
- Total sales
- Average sales or transaction value
- Number of orders or records
- Category and product performance
- Sales trends, if date information is available
- PivotCharts
- Interactive slicers and filters

All metrics will be based on the available dataset and validated calculations.

### 8. Business Summary and Insights

Prepare a one-page summary in Microsoft Word explaining:

- The data cleaning and preparation decisions.
- The statistical and analytical methods used.
- The most important findings from the analysis.
- The insights demonstrated by the charts and dashboard.
- Potential business recommendations supported by the data.
